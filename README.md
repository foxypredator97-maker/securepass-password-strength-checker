# SecurePass - Advanced Password Strength Checker
# Live Demo 
https://securepass-password-strength-checker.onrender.com

## Overview

SecurePass is a cybersecurity-focused web application developed using Python and Flask. It evaluates password strength based on multiple security parameters and provides recommendations for creating stronger passwords.

## Features

* Password Strength Analysis
* Strength Score (0-100)
* Weak / Medium / Strong Classification
* Entropy Calculation
* Password Security Suggestions
* Show / Hide Password
* Strong Password Generator
* Copy Password to Clipboard
* Dynamic Strength Meter
